# DuoCam

Камера для Android (під Motorola Moto g30), у якій **можна змінювати об'єктив прямо під час запису відео**:
Фронтальна · Основна (1×) · Надширока (0,5×) · Макро.

Під час перемикання картинка **плавно розмивається**, камера змінюється "за лаштунками"
(це може тривати 1–2 секунди — це нормально), потім розмиття так само плавно зникає.
Файл відео при цьому **не переривається** — виходить один суцільний MP4 (Movies/DuoCam).

## Як зібрати APK (GitHub Actions)

1. Створіть репозиторій на GitHub і завантажте туди **весь вміст цієї папки** (разом із `.github`).
2. Вкладка **Actions** → **Build APK** → (якщо не стартувало саме) **Run workflow**.
3. Через 3–5 хвилин: завершений запуск → внизу **Artifacts → DuoCam-apk** → `app-debug.apk` → встановити.

## Інтерфейс

| Де | Що |
|---|---|
| Внизу | **Фронт · 1× · 0,5× · Макро** — вибір об'єктива (утримання = призначити камеру вручну) |
| Праворуч по центру | Кнопка запису |
| Вгорі | **Стаб** · **🔦** · **PRO** · **↻ орієнтація** |
| Ліворуч по центру | Повзунок зуму |

### Орієнтація (↻)
Кнопка перемикає: **Авто** (екран і відео повертаються разом із телефоном) → **16:9** (завжди горизонтально) →
**9:16** (завжди вертикально). Відео пишеться 1920×1080 або 1080×1920. Під час запису орієнтація
фіксується (змінити її в процесі не можна — розмір файлу задається на старті).

Якщо картинка на вашому телефоні все ж повернута не так: **утримуйте кнопку «↻»** → «Поворот картинки» →
оберіть корекцію (вона застосовується і до прев'ю, і до відео). Пункт «ℹ Технічні дані» показує значення, які
потрібні для діагностики.

### Стабілізація («Стаб»)
Програмна, на гіроскопі: картинка зсувається/повертається проти тремтіння телефона, по краях
робиться запас-кроп. **Коротке натискання** — увімк./вимк. **Утримання** — налаштування:
ступінь (плавніше ↔ більший кроп, ≈5–20 %), вирівнювання нахилу, та прапорець
**«Інвертувати напрямок»** — увімкніть його, якщо з увімкненою стабілізацією кадр трясе
*сильніше*, ніж без неї (знак осей гіроскопа залежить від телефона).

Якщо тремтіння рук усе ж видно при увімкненій стабілізації: у налаштуваннях стабілізації (утримання «Стаб»)
є повзунок **«Синхронізація з гіроскопом»**. Потрясіть телефоном і потроху зсувайте його, поки тремтіння
не зникне. Внизу вікна показано технічні дані (годинник кадрів, затримка).

### Ліхтарик (🔦)
Постійне світло на задніх камерах (на фронтальній спалаху немає). Лишається ввімкненим при
перемиканні об'єктивів, де спалах є.

### PRO режим
Кнопка відкриває панель: ручна експозиція (ISO + витримка), ручний фокус, експокорекція (EV),
баланс білого. Пункти, яких камера не підтримує (напр. ручні ISO/витримка на деяких бюджетних
телефонах), показуються як «недоступно». Вимкнули PRO — усе повертається в авто.

### Зум
Повзунок завжди вертається в центр. **Вгору** — плавне наближення, **вниз** — плавне віддалення;
чим далі від центру, тим швидше. Зум апаратний (якість краща за цифровий), до 8×.
При зміні об'єктива зум скидається на 1×.

## Якщо якогось об'єктива не знайдено

Утримуйте будь-яку кнопку об'єктива → **«ℹ Усі камери телефону»**: це повний список того, що система
віддає застосунку (id, фокусна, Мп, фізичні камери, приховані id). Кнопка «Поділитися» відправляє його текстом.


Не всі телефони віддають сторонім застосункам надширокий кут і макро. DuoCam шукає їх сам.
Якщо кнопка напівпрозора — утримуйте її й оберіть камеру зі списку (id, фокусна, Мп, мін. дистанція).
«Авто» повертає автовизначення, «Приховати» — вимикає кнопку. Якщо камери немає в списку взагалі —
система не віддає її сторонім застосункам (обмеження телефона).

## Технічно

- Camera2 → `SurfaceTexture` → OpenGL ES 2.0 → одночасно екран і відеокодер (H.264, 1080p/30, 16 Мбіт/с) + AAC.
- Розмиття — шейдер на зменшеній копії кадру; стабілізація — афінне перетворення у вершинному шейдері,
  поправка береться з буфера гіроскопа за часом зйомки кадру.
- Android 11+ (API 30), цільовий API 31. Зовнішніх залежностей немає.
